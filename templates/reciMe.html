ReciMe: YOUR FAVORITE RECIPE FINDER

Find exactly what you’re craving — no preamble, no frills. Just what you want.

Born out of the love for good food and the frustration of scattered, unreliable recipe platforms, ReciMe combines the power of the Edamam API—bringing you official, nutrition-backed recipes from top sources—with the creativity and community of user-generated recipes stored securely on Firebase.

APP FEATURES

The app consists of several key features that make it a powerful and user-friendly recipe platform:

  • ⭐Home Page
  • ⭐Recipe Page
  • ⭐Recipe Details
  • ⭐Admin Abilities
  • ⭐Create Recipes
  • ⭐My Recipes

For the Recipe Page, users can view available recipes, sort recipes based on category (health labels, cuisine types, ingredients, instructions, etc.), and toggle between Edamam API recipes and community (user-created) recipes.

For the Recipe Details Page, users can view detailed information about each recipe including health labels, cuisine types, ingredients, instructions, etc. Leave ratings, read reviews and receive assistance from a chatbot.

For the My Recipes Page, users can view their created and saved recipes, read reviews and leave ratings and reviews and have a quick link to the Create Recipe form.

For the Create Recipes Page, users can create new recipes with required fields like name, ingredients, and instructions. They can also add optional information like labels, description, and image. Upon successful creation, a toast notification is displayed.

The Admin Page allows administrators to manage user-generated recipes. From there, an admin can view unapproved recipes and choose to verify and publish them.

WHAT I WORKED ON

  • Sort Recipes: Implemented sorting by category, health labels, ingredients, and instructions.
  • Edamam API Integration: Fetched recipes and allowed toggling between API and community recipes.
  • View Recipes: Allowed the display of 20 recipes per view and refresh results dynamically for improved data handling and user experience.

PROJECT ANALYSIS

  • Technologies Used: JavaScript, React
  • APIs Integrated: Edamam Recipe Search API for official recipes
  • Database Management: Firebase Firestore for user-generated recipes and user data
  • UI/UX Design: Material UI for responsive design and intuitive user experience

Strengths

  • The UX on this project is very intuitive and allows the user to get a true grasp of every recipe, as well as all the necessary information
  • The project is easily scalable, allowing for the implementation of more features
  • Toasts which provide quick notifications without disrupting the user’s interaction flow

Weaknesses

  • Edamam recipes were not given the ability to leave reviews or chatbot access.
  • Passwords on the database are currently being stored as text objects and are not being encrypted before storage

Opportunities for Improvement

  • Lazy Loading: with more and more community recipes available it would be more efficient to load a small subset rather than the entire database each query
  • Could save recipe images in the Firebase Storage so that users are able to upload recipe images.

CONCLUSION

ReciMe is a robust, intuitive recipe platform combining official API recipes with community contributions. Through this project, I strengthened my skills in API integration, UI/UX design, Firebase database management, and building scalable features while ensuring a smooth, engaging user experience.
