SpotiVibe

SpotiVibe is a full-stack web application built using React, Express, Firebase, and the Spotify API. The goal of the project was to extend Spotify beyond passive listening by creating a space where users can express their music taste, interact with others, and engage in music-related discussions.

Although users authenticate using Spotify, SpotiVibe maintains a separate user profile system. This allows users to customize their profiles, control visibility, and interact with others independently of their Spotify accounts.

WHY SpotiVibe?

While Spotify allows users to stream songs and follow friends, it does not allow them to express their music taste beyond playlisting. SpotiVibe fills this gap by transforming music listening into an interactive and community-driven experience.

Through SpotiVibe, users can discover new music and artists, track their listening habits, and engage in conversations about music news and trends. In addition, users can create discussion boards, interact with posts, and easily search forums to find relevant topics.

FEATURES

I worked extensively on the forum page, implementing core interactive features such as post creation, liking posts, and commenting. These features allowed users to actively engage in discussions rather than passively consuming content, reinforcing SpotiVibe’s goal of being a community-driven platform.

I also contributed to improving forum navigation by enabling users to search forums by name, making it easier to discover relevant discussions as the platform scaled.

SpotiVibe consists of several pages designed to highlight music discovery, personalization, and social interaction.

  • Liked Songs: Displays a user’s liked songs along with album artwork.
  • Forum: Allows users to create and engage in music-related discussions.
  • Top Artists & Songs: Shows listening data for all time, last year, and last month.
  • User Profile: Allows users to edit their profile, display selected artists or songs, and set their profile as public or private.
  • Discover: Displays all public users so profiles can be explored and messages sent.
  • Inbox: Enables direct messaging between users.

CHALLENGES FACED

One of the main challenges was managing an ambitious feature scope under a tight timeline. As the team explored functionality beyond classroom learning, this introduced more bugs and increased debugging time.

Additional challenges included the lack of personalization on the discovery page. Mantine UI also proved difficult to work with, as it occasionally disrupted layout consistency across different pages.

CONCLUSION

SpotiVibe demonstrates how music platforms can evolve beyond listening by fostering expression, discussion, and community. Some additional enhancements that could have been implemented if time permitted included allowing users to display and link songs or playlists on their profiles, adding interactive music statistics visualizations using charts and graphs, and enabling nested comments with profile navigation.
