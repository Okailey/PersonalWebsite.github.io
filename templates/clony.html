CLONY

A web application mimicking ChatGPT using OpenAI's API. Built with React for the frontend and Express.js for the backend, this project demonstrates how to manage continuous conversations with a chatbot while providing a clean user interface.

PROCESS

The project was developed in two main parts:

  • Backend (Express.js): Set up endpoints to securely send and receive messages from the OpenAI API. Implemented message handling that maintains conversation history for context-aware responses.
  • Frontend (React): Built an interactive chat interface differentiating between user messages and chatbot responses. Axios was used to communicate with the backend.

FEATURES

  • Send messages and receive dynamic, context-aware responses from the GPT-3.5-turbo model.
  • Maintain conversation continuity, so each message builds on previous interactions.
  • Simple, responsive chat UI that works across devices.

CONCLUSION

This project strengthened my understanding of full-stack development, API integration, and creating interactive user interfaces. It also demonstrated the challenges of managing conversation state and maintaining clean, responsive design while working with real-time data.
